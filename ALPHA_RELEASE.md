# Aster Content Hub 0.1.0-alpha.1

First public Windows x64 testing release.

- Cinematic Home, online addon search, Library, Favorites and Continue Watching.
- Stremio-compatible catalogs and stream providers, with one-click Play and optional source selection.
- Embedded mpv, fullscreen, audio/subtitle controls and in-player source switching.
- TV seasons and episodes, remembered progress, Next episode and optional autoplay.
- Separate local profiles with optional cloud sync and one-use device pairing. No email required.
- Service connections, themed settings, collection backups and restore.

## Downloads

Use **AsterContentHub-Setup-0.1.0-alpha.1-x64.exe** for installation or **AsterContentHub-0.1.0-alpha.1-x64.exe** directly. Install mpv separately for broad codec support. Windows x64 and WebView2 are required. The build is unsigned and updates are manual.

No streaming subscriptions or commercial films are included. Install your own catalog and stream-provider addons and use authorized sources.

## Getting started

Open Profiles & sync to enable sync. On one connected device choose Add another device; on the second device choose Connect existing profile and paste the temporary code. Keep a backup and at least one connected device because email recovery is not provided.

This is an alpha: consult the README for supported services and limitations. Native iOS/tvOS clients, IPTV DVR, casting and automatic app updates are not included.

Report issues with reproduction steps, app/Windows version and selected player. Do not include credentials, private playback links or pairing codes.
